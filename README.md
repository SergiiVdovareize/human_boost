# Human Boost

Неофіційне Chrome-розширення (Manifest V3) для вчителів на платформі [human.ua](https://human.ua). Прискорює роботу з журналом, розкладом і перевіркою завдань.

**Репозиторій:** [SergiiVdovareize/human_boost](https://github.com/SergiiVdovareize/human_boost)

---

## Можливості

### Журнал оцінок
- **Копіювання оцінок** — з «Завдання» в «Заняття» за обраний період (комірки з «Н» не змінюються).
- **Виставлення оцінок** — випадково в діапазоні з цільовим % заповнення або імпорт з `.csv` / `.xlsx` / `.xls`.
- **Видалення оцінок** — усі або лише вибраний бал для обраних учнів / періоду.
- **Статистика оцінок** — скільки разів виставлено кожен бал у класі.
- **Підсвічування обовʼязкових робіт** і порожніх оцінок за ними.
- **Підсвічування розбіжностей** оцінок у парі «Заняття» / «Завдання».
- **Статуси учнів** — вибув / сімейна форма / за кордоном; бейджі та підказки щодо помилкових «Н».

### Розклад
- **Дедлайни завдань** — масове виставлення дати здачі («Наступний урок», «Через урок» тощо).
- **Підсвічування неопублікованих уроків** і невиданих завдань.
- **Іконки типу уроку** — онлайн / самостійне опрацювання.

### Урок і перевірка робіт
- **«Не видно роботи»** — якщо в учня немає файлів і посилань: повідомлення в чат + повернення на доопрацювання.
- Кнопка не показується, якщо учень додав файл або посилання.

### Підсумкове оцінювання
- Підсвічування обовʼязкових / контрольних робіт на сторінці thematic assessment.
- Статуси учнів у списку.

### Налаштування та синхронізація
- Бічна панель з окремими перемикачами підсвічувань.
- Збереження налаштувань і статусів у Chrome Storage.
- Опційна хмарна синхронізація між пристроями (якщо налаштовано sync API).

## Використання

1. Відкрийте потрібну сторінку на human.ua (журнал, розклад, урок).
2. Натисніть кнопку Human Boost у правому нижньому куті.
3. Оберіть автоматизацію або змініть налаштування підсвічування.
