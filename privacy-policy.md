# Політика конфіденційності

**Останнє оновлення:** 25 листопада 2026 року

## 1. Загальна інформація

Ця Політика пояснює, як Chrome-розширення **Human Boost** («Застосунок») обробляє дані під час роботи на платформі [human.ua](https://human.ua).

## 2. Які дані обробляються

Залежно від функцій Застосунку можуть оброблятися:

- **Вміст сторінок human.ua** у відкритій вкладці (журнал, розклад, уроки) — лише для виконання дій і підсвічування, які ви запускаєте.
- **Налаштування Застосунку** (перемикачі підсвічування тощо) у `chrome.storage`.
- **Статуси учнів**, які ви самі призначаєте в Застосунку (наприклад: вибув, сімейна форма, за кордоном), з привʼязкою до ідентифікаторів класу/учня на human.ua.
- **Ідентифікатор користувача human.ua (`userId`)**, якщо увімкнена опційна хмарна синхронізація.

Ми **не** збираємо паролі human.ua, платіжні дані чи історію відвідувань інших сайтів.

## 3. Як використовуються дані

- Для автоматизації та підсвічування на human.ua за вашою дією.
- Для збереження ваших налаштувань і статусів між сесіями.
- Для опційної синхронізації цих налаштувань/статусів між вашими пристроями через sync API розробника (якщо він налаштований у збірці).

## 4. Збереження та передача

- Основне сховище: **`chrome.storage`** у вашому браузері.
- Опційно: синхронізація на сервер розробника (`api.vdovareize.me` або інший URL з конфігурації збірки) під ключем `userId`.
- Дані не продаються третім сторонам і не використовуються для кредитного скорингу.

## 5. Ваші можливості

- Змінити або скинути дані Застосунку через його інтерфейс / очищення даних розширення.
- Вимкнути або видалити Застосунок у `chrome://extensions`.
